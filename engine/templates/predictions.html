🧮 Methodology

For each name with 2+ calls we take the median gap between appearances (robust to one freak gap) as its cycle, and its expected return is the last call plus that cycle. A name is "on the clock" from 30 days before to 60 days after its expected date.

The % this week is a probability: the name's arrival rate (shrunk toward the site-wide base rate, so thin history doesn't overclaim) run through a Poisson model over the next 7 days.

The scorecard is honest by construction: every day since January 2026 is re-predicted using only data available that morning, then checked against what actually got called. No stored state, no hindsight — the ledger can't drift from the day files. "Better than chance" compares the real hit count with what random same-size sets drawn from the then-known name pool would have scored.

This is fan speculation, not a crystal ball. Carmen picks names, not algorithms.
